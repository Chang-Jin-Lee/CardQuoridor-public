버튼은 이메일 앱을 엽니다. 열리지 않으면 수신 주소와 제목을 복사해 사용 중인 메일 서비스에서 보내주세요. 이 페이지 자체에는 접수 양식이나 자동 삭제 기능이 없습니다.

현재는 운영팀의 수동 확인·삭제가 필요합니다.

모바일 공개 출시 준비 단계이며 앱 내 계정 삭제 기능은 아직 제공되지 않습니다. 메일 발송만으로 Unity 계정이나 서버 기록이 자동 삭제되지는 않습니다. 운영팀이 계정 식별과 소유 확인, 실제 클라우드 삭제 절차를 진행해야 합니다. 앱 내 삭제 기능은 스토어 출시 전에 구현·검증할 항목입니다.

1. 요청할 때 필요한 정보

다음 중 알고 있는 정보만 적어주세요. 현재 앱에 Player ID 확인 화면이 제공된다고 전제하지 않습니다.

  • 삭제 범위: 익명 계정과 관련 데이터 전체, 또는 문의 메일 등 특정 데이터만 삭제할지 알려주세요.
  • Unity Authentication Player ID: 이미 알고 있거나 보유한 화면·기록에서 안전하게 확인할 수 있을 때 적어주세요. Player ID는 계정 식별자이며 인증 토큰과 다릅니다.
  • 보조 정보: 사용한 닉네임, 이용한 모드, 마지막 이용 시각과 시간대, 앱 버전·빌드, 기기 모델·OS를 알려주세요. 자체 서버 기록에 한정한 요청이라면 관련 닉네임과 이용 시각이 도움이 됩니다.

Player ID를 모르면 “Player ID를 모릅니다”라고 적어 요청할 수 있습니다. 닉네임만으로는 동일인 확인이 어려울 수 있어 운영팀이 추가로 필요한 최소 정보를 회신합니다. 익명 인증 특성상 기존 기기 정보까지 없어지면 계정을 특정하지 못할 수 있으며, 이 경우 확인 가능한 범위와 제한을 설명합니다.

비밀번호, 인증·세션 토큰, 입장 티켓, 전체 IP 주소, 신분증 사본은 먼저 보내지 마세요. 삭제 요청에 결제나 구매 증빙은 필요하지 않습니다. 식별 정보와 로그를 공개 저장소에 게시하지 마세요.

2. 요청 후 처리

  1. 운영팀이 메일을 확인하고 요청 범위와 계정 소유를 확인합니다. 추가 확인이 필요하면 같은 메일로 안내합니다.
  2. 확인된 계정에 대해 Unity Authentication 계정 삭제와 관련 자체 서버 기록의 삭제를 진행합니다. Lobby·Relay 등은 별도 서비스 절차가 필요할 수 있어 해당 기록에 대한 삭제 요청도 확인합니다.
  3. 예상 소요와 처리 상태를 안내하고, 완료 후 삭제 범위와 남는 기록·사유가 있다면 회신합니다. 진행 상황은 보낸 요청 메일에 답장하여 문의할 수 있습니다.

현재 고정 처리기한이 설정된 자동 삭제 서비스는 제공하지 않습니다. 실제 확인과 서비스 제공자의 처리가 필요한 수동 요청입니다. 이 안내는 삭제 기능이 이미 앱에 구현되었다는 의미가 아닙니다.

3. 삭제 대상과 보존 범위

삭제 요청 대상
식별 가능한 Unity 익명 계정과 해당 계정에 연결된 개인정보, 자체 서버에 남아 있는 관련 접속·경기 정보, 운영팀에 보낸 문의 자료입니다. 요청 범위와 실제 남아 있는 기록을 확인해 처리합니다.
자동 정리되는 일부 임시 기록
자체 매칭 서버의 임시 메모리는 기본 20초 heartbeat 부재 시 정리 대상이며, 경기 파일 로그는 기본 7일 초과 시 매시간 정리합니다. 이미 정리된 기록은 삭제 시점에 남아 있지 않을 수 있습니다.
별도 확인이 필요한 기록
접속·Docker·프록시 로그, 백업과 문의 메일의 보존 상한·삭제 운영은 아직 확정·검증되지 않았습니다. Unity 공식 문서상 Authentication 계정은 삭제 전까지, Relay 개인정보는 30일, Lobby 로그의 Player ID는 최대 30일 보존되며 자체 서버 기준과 별개입니다. 이 범위를 모두 7일 내 삭제한다고 보장하지 않습니다.
기기에 남는 정보
운영팀은 이메일 요청으로 기기의 설정·토큰을 원격 삭제할 수 없습니다. 운영체제의 앱 데이터 삭제 또는 앱 제거·백업 관리가 필요할 수 있습니다. 반대로 앱을 지우거나 방을 나가도 클라우드 계정이 자동 삭제되지는 않습니다.

법령상 보존 등으로 삭제가 제한되는 정보가 실제로 있다면 정보 종류, 사유와 보존 범위를 개별 안내합니다. 계정 삭제 후에는 기존 익명 계정에 다시 접근하지 못할 수 있으며, 온라인 기능 재이용 시 새 익명 계정이 만들어질 수 있습니다.

자세한 처리 목적과 서비스별 공식 링크는 개인정보처리방침의 보존·삭제 안내에서 확인하세요.
