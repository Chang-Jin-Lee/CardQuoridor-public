1. 처리하는 정보와 목적

기기에 저장되는 설정
입력한 닉네임과 매칭 서버 주소, 해상도·화면 모드 등의 설정이 다음 실행에서 입력과 화면을 복원하기 위해 기기에 저장됩니다. 온라인에 접속하기 전에도 입력값이 기기에 남을 수 있습니다.
자체 매칭·게임 서버
온라인 연결과 경기 진행을 위해 닉네임, 방 이름, 임시 이용자 식별자, 세션 인증 정보, 입장 정보, 방·매칭 상태, 경기 식별자, 좌석·접속 식별자와 경기 명령·상태를 처리합니다.
접속·경기 로그
장애 진단과 보안 대응에 접속 IP, HTTP 요청 경로·응답 상태, 경기 식별자, 접속 승인·이탈·경기 종료 같은 운영 기록을 사용합니다. 프록시 구성에 따라 서버에 기록되는 IP가 달라질 수 있습니다.
Unity Gaming Services 온라인 방
익명 Authentication Player ID와 세션 토큰, Multiplayer Sessions/Lobby, Relay 및 QoS의 방·연결 정보를 처리합니다. Unity 서비스에는 IP, Player ID, 대략적 위치, 서비스 이용·진단 정보가 전달되거나 생성될 수 있습니다. 인증·방 검색·연결 품질과 온라인 기능 운영에 필요하며, Unity의 Relay 공개 자료에는 일부 정보의 서비스 분석 목적도 기재되어 있습니다. 대략적 위치는 정밀 GPS 위치를 뜻하지 않습니다.
직접 보내는 문의
문의에 회신하고 문제를 확인하기 위해 발신 이메일 주소, 본문, 이용자가 첨부한 기기·빌드 정보, 화면·로그 및 요청 처리 내역을 처리합니다. 문제 확인에 필요한 정보만 보내주세요.

실명·전화번호·연락처를 닉네임이나 방 이름으로 입력할 필요가 없습니다. 현재 확인한 앱 구성에는 별도의 광고 SDK 또는 인앱 결제 SDK를 추가하지 않았습니다. 이 사실은 Unity 서비스의 운영·진단 정보 처리까지 없다는 뜻은 아닙니다.

핫시트는 한 기기에서 두 사람이 번갈아 두는 모드입니다. 온라인 기능을 선택하지 않은 최초 실행의 SDK 통신 여부는 최종 배포 앱에서 추가 확인이 필요하므로, 앱 전체가 언제나 네트워크 요청 없이 동작한다고 안내하지 않습니다.

2. 다른 이용자와 서비스 제공자

온라인 방 목록·대기방·경기 화면에는 닉네임과 방 이름, 상대 정보와 게임 진행 상태가 다른 참가자에게 표시될 수 있습니다. 개인 연락처나 민감한 내용을 입력하지 마세요.

Unity Gaming Services는 온라인 인증, Sessions/Lobby, Relay 및 연결 품질 측정에 사용됩니다. 이들 서비스의 처리는 자체 서버와 별개입니다. Unity 서비스의 처리 위치는 이용하는 서비스와 연결 지역 등에 따라 달라질 수 있으며, 해당 프로젝트의 실제 처리 지역과 국외 이전 세부사항은 출시 전 확인 항목입니다. 특정 국가 내에서만 처리된다고 보장하지 않습니다.

서비스 제공자의 원문 안내:

  • Unity 게임 플레이어·앱 이용자 개인정보처리방침
  • Unity Authentication 개인정보 안내
  • Unity Lobby 개인정보 안내
  • Unity Relay 개인정보 안내 · Relay 처리 정보 상세

위 문서는 Unity 서비스의 처리 범위를 설명합니다. CardQuoridor 운영팀의 자체 서버·설정·지원 메일 처리에는 이 방침이 함께 적용됩니다.
